# sandytheadventurer.github.io

Personal portfolio of Sandeep Suresh — live at https://sandytheadventurer.github.io/

Built with React + Vite. Content lives in `src/data.js`; the "More on GitHub" list is fetched live from the GitHub API.

```sh
npm install
npm run dev      # local dev server
npm run deploy   # build and publish dist/ to the gh-pages branch
```
